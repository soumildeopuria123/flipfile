# Quarterly operations review

Flipfile converts documents inside the browser window. Nothing is uploaded to a server, which means a contract, an invoice or a screenshot never leaves the machine it was created on. The engine rasterises images through the Canvas API and lays out text with embedded standard fonts, so the resulting PDF keeps selectable text instead of a flat picture.

## Highlights

- Shipped the offline converter to every desktop build
- Cut average conversion time by 40% after switching renderers
- Reduced support tickets by half quarter over quarter

### Numbers that matter

| Metric | Q1 | Q2 |
| --- | --- | --- |
| Conversions | 12,400 | 31,900 |
| Median time | 1.9s | 0.8s |

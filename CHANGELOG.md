# Changelog

## 1.0.0

First working release.

- Two-way conversion: any supported file to PDF, and PDFs back to PNG, JPG or
  plain text.
- Batch queue with per-file status, individual save and a zipped download of every
  output.
- Fit-to-file or A4 page size, PNG/JPG/text output, 1×–3× render resolution.
- Real selectable text in generated PDFs, with Noto Sans for Latin, Greek and
  Cyrillic and Noto Sans SC for Chinese and Japanese, embedded as subsets.
- Binary and archive inputs rejected with an explanation rather than converted.
- Everything runs in the tab; no uploads, no accounts, no storage.
